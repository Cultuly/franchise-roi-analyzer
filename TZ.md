# Техническое задание на проект: «Точка Роста»

## 1. Цель проекта
Создание веб-сервиса для анализа рентабельности франшиз предприятий общественного питания с учетом региональных экономических особенностей России. Система помогает начинающим предпринимателям оценить финансовую эффективность открытия точки общепита по франшизе в конкретном регионе с возможностью настройки индивидуальных параметров проекта.

## 2. Роли пользователей
Пользователь: Просмотр основных возможностей сервиса, выполнение расчетов рентабельности без возможности сохранения результатов, экспорт результатов анализа в PDF.
Администратор: Управление данными о регионах, добавление новых типов заведений, настройка коэффициентов расчетов.

## 3. Модели данных (сущности)
* Region (Регион): Хранение экономических показателей регионов России для расчета региональной адаптации.
* Franchise (Тип франшизы): Классификация заведений общепита по типам с соответствующими коэффициентами расчета.
* ProfitabilityAnalysis (Анализ рентабельности): Результаты расчетов финансовых показателей для конкретного сценария.

## 4. Ключевой функционал (User Stories)
* Подбор региона и параметров: Пользователь выбирает регион из списка и указывает параметры будущего заведения (площадь, количество сотрудников, средний чек, паушальный взнос), система автоматически рассчитывает региональные коэффициенты для аренды и заработной платы.
* Финансовый анализ: Система проводит комплексный расчет финансовых показателей (срок окупаемости, ежемесячная прибыль, ROI, точка безубыточности) с использованием сложных математических формул и региональных коэффициентов.
* Визуализация результатов: Пользователь получает интерактивные графики окупаемости проекта и ежемесячной динамики финансовых показателей, с возможностью изменения масштаба для детального анализа.
* Экспорт отчета: Пользователь может сгенерировать PDF-отчет с результатами анализа, включающий все графики и финансовые показатели для дальнейшего использования при принятии решения.
* Сравнение сценариев: Пользователь может провести несколько расчетов с разными параметрами для сравнения эффективности различных сценариев открытия франшизы.

## 5. Внешние интеграции и аналитика
* Аналитика: Применение алгоритмов для расчета точки безубыточности, срока окупаемости и годовой доходности.
* Визуализация: Интеграция Plotly.js для создания интерактивных графиков окупаемости проекта и динамики финансовых показателей с возможностью детального анализа.
* Экспорт данных: Использование библиотек html2canvas и jsPDF для генерации профессиональных PDF-отчетов с сохранением всех графиков и финансовых показателей.
* Данные о регионах: Загрузка реальных экономических показателей регионов России из фикстур, подготовленных на основе данных Росстата и других официальных источников для обеспечения точности расчетов.
