# Техническое задание на проект: "Система анализа рентабельности франшиз общепита"

## 1. Цель проекта
Создание сервиса для анализа рентабельности франшиз общепита с учетом региональных особенностей. Система помогает начинающим предпринимателям оценить потенциальную прибыльность открытия франшизы в конкретном регионе России.

## 2. Роли пользователей
- Гость: просмотр каталога франшиз, базовые расчеты рентабельности
- Зарегистрированный пользователь: сохранение расчетов, сравнение разных регионов
- Администратор: управление данными о франшизах и регионах

## 3. Модели данных
- Franchise (Франшиза): название, описание, стоимость франшизы, роялти, срок окупаемости, категория
- Region (Регион): название, население, средний доход, арендная ставка за м², индекс потребительской активности
- ProfitabilityAnalysis (Анализ рентабельности): связь с франшизой и регионом, прогноз выручки, прогноз расходов, ROI, период окупаемости

## 4. Ключевой функционал
- Расчет рентабельности франшизы в выбранном регионе с учетом локальных экономических показателей
- Визуализация финансовых прогнозов с помощью Plotly
- Сравнение нескольких регионов для одной франшизы

## 5. Внешние интеграции и аналитика
- Интеграция с API Росстата для получения демографических данных по регионам
- Аналитика с использованием Pandas для финансовых расчетов
- Визуализация данных с помощью Plotly
